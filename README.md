# ClassConnect – Product Management Case Study

## About the Project
ClassConnect is a proposed college class communication platform designed to simplify communication between students, professors and college administration.

## Problem Statement
Students and professors often rely on multiple WhatsApp groups for class-related communication. Important announcements can get buried among unrelated messages, leading to missed updates and confusion.

## Product Goal
To provide a centralized platform for class announcements, timetable updates, class cancellations and rescheduling notifications.

## Target Users
- Students
- Professors
- College Administration

## Project Objectives
- Understand user problems through research.
- Analyze existing communication solutions.
- Define product vision and strategy.
- Identify and prioritize MVP features.
- Create a Product Requirements Document (PRD).
- Design a prototype using Figma.
