# ClassConnect – Product Management Case Study

## About the Project
ClassConnect is a proposed college class communication platform designed to simplify communication between students, professors and college administration.

## Problem Statement
Students and professors often rely on multiple WhatsApp groups for class-related communication. Important announcements can get buried among unrelated messages, leading to missed updates and confusion.

## Product Goal
To provide a centralized platform for class announcements, timetable updates, class cancellations and rescheduling notifications.

## Target Users
- Students
- Professors
- College Administration

## Project Objectives
- Understand user problems through research.
- Analyze existing communication solutions.
- Define product vision and strategy.
- Identify and prioritize MVP features.
- Create a Product Requirements Document (PRD).
- Design a prototype using Figma.

## Key Product Screens

The proposed ClassConnect experience includes:

- Announcements – View important college updates.
- Weekly Timetable – Access weekly class schedules.
- Notifications – Receive important updates and reminders.

## MVP Features

- Student, Professor and Admin Login
- Latest Announcements
- Class Cancellation and Rescheduling Updates
- Weekly Timetable
- In-app and Email Notifications
- Basic Admin Announcement Management

## Research Limitations

The initial student survey received 3 responses. The findings are preliminary and further student research, professor interviews and pilot validation are required.

## Product Success Metrics

**North Star Metric:** On-Time Announcement View Rate.

Supporting metrics include:
- Announcement View Rate
- Notification Delivery Rate
- Weekly Active Students
- Timetable Update View Rate
- User Satisfaction
